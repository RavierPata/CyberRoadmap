Learning Paths

Step-by-step roadmaps for cybersecurity careers.

🔵 SOC Analyst Path

Monitors networks, hunts threats, and responds to incidents.

  1. 1. IT Fundamentals
    • OSI Model & Networking (TCP/IP, DNS)
    • Windows Event Viewer & Linux Syslogs
  2. 2. Security Core
    • Attacks: Malware, Phishing, & DDoS
    • Defenses: Firewalls, IPS, & Antivirus
  3. 3. The SOC Toolkit
    • SIEM: Splunk, Sentinel, or QRadar
    • MITRE ATT&CK Framework & Threat Intel
  4. 4. Response & Level Up
    • NIST Incident Response Lifecycle
    • Hands-on Labs: TryHackMe or Blue Team Labs
